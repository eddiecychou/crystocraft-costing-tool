# Catalogue image sizes and portrait infographics — V8.20, 30 October 2026

Owner authorized Standard / Large / Full page options for every selected image,
portrait pages for tall infographics, and deployment after the required checks.
This extends the flexible Marketing catalogue release; the separate Range PDF
export is unchanged. No existing catalogue needs a data migration.

## Behavior and stored contract

- Every selected picture has a saved size selector. The existing string
  `selected_images` array still owns selection and ordering. New optional
  `image_layouts: [{url, size}]` rows use `standard | large | full`, keyed by URL,
  so reordering, hero changes and deselect/reselect preserve the picture's choice.
  Missing/invalid legacy choices display Standard.
- An image-size change uses a Firestore transaction, reading the latest item and
  merging only that image's choice. Concurrent edits to other pictures retry
  against current data. Only `image_layouts` is updated; all content, ordering,
  product links and page-layout choices remain intact. Missing/deselected images
  are refused. Saving/error feedback is visible; failure restores the old choice.
- A Standard first picture remains the hero beside the product copy. Supporting
  Standard pictures have galleries of up to four, without thumbnail strips.
  Consecutive groups are balanced (five pictures become three plus two).
  Large images use up to two per landscape page. Full page gives one picture a
  dedicated page with a small product heading; long specifications stay on their
  own continuation pages. Explicitly enlarged first images are never duplicated
  as a second hero. Product/image order and full text are retained.
- Full-page pictures use actual loaded dimensions. Taller-than-wide images get
  A4 portrait; square/wide images get A4 landscape. No rotation, crop, text
  extraction or image rewriting. Unavailable dimensions/images block printing.
- Screen sheet dimensions and scaled previews match each orientation. Named
  `oc-catalogue-landscape` / `oc-catalogue-portrait` @page rules switch print size
  per sheet, then return to landscape. Print styles remain mounted only while
  CataloguePreview is open (L-30). The approach follows the
  [W3C named-page and page-size specification](https://www.w3.org/TR/css-page-3/#using-named-pages).
- The builder header wraps at phone widths; image dragging remains on the
  photograph, separate from its selector. Preview retains image/text preflight.
