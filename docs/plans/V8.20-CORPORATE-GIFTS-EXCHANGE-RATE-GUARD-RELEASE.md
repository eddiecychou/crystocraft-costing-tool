# Corporate Gifts exchange-rate publish guard release

Corporate Gifts Pricing reads configured exchange rates before publishing.
It pauses publishing if a required rate is still loading, missing, invalid or
unavailable. An explicit retry reloads Settings. A successful publish uses the
same tier cost for the buyer price, representative tier price and product
summary. HKD-only costing can publish without unrelated rate data.

  fictional price records. Loading the rate by itself wrote nothing.
