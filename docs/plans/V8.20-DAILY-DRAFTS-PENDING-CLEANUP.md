## Maintenance lesson

Separate a large card with grouped view/actions/limits while leaving state and
write orchestration in the page. Preserve the keyed boundary and recover imports
as well as markup when proving whole-page parity. Fixtures must honor synchronous
SDK contracts (storage ref, serverTimestamp), and imported React in a custom
esbuild namespace needs resolveDir. A controlled child fixture tests the parent
contract, not the child's internal search. When the deployed queue is empty,
record the gap and use fictional populated evidence; never seed business records
or send real email solely to make a presentation smoke check look complete.
