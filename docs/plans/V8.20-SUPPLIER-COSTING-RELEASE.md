# Range costing and supplier quote release

Release source `298930af349539d7440da62d5489d9ec348a8b13` on GitHub main. Production verification completed on 26 November 2026 at 02:53 AEDT.

## Changes

- Range identifies the missing input on affected estimates and blocks costing publication until the inputs are complete. Staff can save a draft. A blank quantity-tier cost falls back to the base cost and an explicit zero stays zero.
- Corporate Gifts, Crystal Components, and Crystocraft Range share the unit-cost inputs for main prices and quantity tiers. Existing finer precision stays valid. Adding a source document to an existing Range quote saves only the attachments when the quote terms are unchanged.
- Corporate Gifts saves the selected quote and clears other preferred flags in one transaction from both the product quote editor and supplier quick-add. Explicit concurrent selections retry and the last successful selection takes effect. Editing unrelated terms preserves a concurrent preference or attachment change.
