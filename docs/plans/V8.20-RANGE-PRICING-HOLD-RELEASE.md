# Range costing hold release

Range Costing now supports per-product holds with a reason. Saving a hold
changes only its private status and audit fields. Publication checks the
current hold and costing in a transaction. Firestore rules also guard
older editor sessions. B0016 continues to use its built-in hold. The existing
customer price calculation still uses the saved variant price and the buyer
factor. [Implementation notes](V8.20-RANGE-PRICING-HOLD-REVIEW.md#local-implementation)
