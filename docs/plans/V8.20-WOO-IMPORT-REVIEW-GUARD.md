# WooCommerce import review guard

WooCommerce Sync shows **Needs review** when the order header is missing and saved lines remain under its stable Woo order ID. The status is derived from Firestore on load and checked again on import. The read checks for any line, including historical lines with no sequence number. If a read fails, the import stops. A clean import still saves one draft and its lines together. A retry with an existing header returns that order without writing again.

This release adds a guard for surviving order lines. Review of ledger-only records and recovery of historical orders remain separate. No historical order, line, invoice or UC record was changed in production, and there was no migration or rules release.

## Fictional verification

Five emulator tests ran the actual importer and WooCommerce Sync page against current Firestore rules. A fresh order created one draft and one line with no invoice or UC allocation. A changed-payload retry preserved the original header and lines. Two sessions importing concurrently acknowledged one saved order. For a missing header with a surviving line, retries left the header absent and the original line intact. Failure to read lines stopped the import. A Woo-only staff profile remained denied by Shipping rules. The page displayed **Needs review** for known surviving lines and also when a stale page found them at import time.
