## Buyer workflow

**My Orders → Sales Invoice History** reads the approved buyer’s issued OC invoices and individually attributable, confirmed JES invoices. The server derives company identity from the login. Shipping staff retain direct access to full records. The buyer receives only summary fields or the fields used to print and export the selected invoice.

New OC links include the order ID and exact SI. Print and Excel recheck the document before exporting. A buyer with an old order-only bookmark can reopen the invoice from history. Earlier split or reissued invoices with verified receipts and ledger records retain their separate totals. If the order now belongs to another SI, an exact confirmed JES copy can still open. Otherwise the historical entry shows **Original unavailable**. Unresolved ownership or conflicting issuance evidence withholds the record. A failed source shows a retry action alongside any rows the other source returned.
