# Supplier quote attachment preparation release

Corporate Gifts, Crystocraft Range and Crystal Components share attachment
preparation. PDFs retain their original bytes. Supplier photos are stored as
colour JPEGs with a 2,400-pixel maximum edge, and new-quote extraction receives
a separate greyscale PNG. Existing quote attachments use the existing
attachment-only transaction when the approved terms are unchanged.

## Fictional-file verification

The hash-verified module was exercised in the deployed browser with a valid
fictional PDF and a generated 3,000 × 240 colour image on both origins.
PDF upload/extraction preserved the original bytes. The image prepared for
upload was a 2,400 × 192 colour JPEG. The independent extraction payload was
a 2,400 × 192 greyscale PNG with the existing contrast adjustment.

The exact release checkout's Chrome form harness was rerun after publication.
It uses the real editors with isolated Firestore, Storage and extraction
boundaries. All ten checks passed, including new and existing quote routes
with PDF and photo fixtures across all three catalogue sections. New quotes
called the extraction fixture once. Adding an attachment and reopening a
saved quote preserved the original attachments, unit cost and tiers, MOQ,
tooling, notes and preferred-supplier status. An attachment edit in a second
session was rejected without overwriting it, and concurrent pricing was
preserved. No live quote, Storage object or extraction service was modified.
