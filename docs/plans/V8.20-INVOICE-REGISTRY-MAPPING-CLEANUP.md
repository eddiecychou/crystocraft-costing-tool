# V8.20 Shipping invoice registry mapping

shipment save. The helper preserves computed-total versus stated-PI fallback,
blank and zero values, accounting fields and external order references.
ShipmentForm owns save sequencing, the invoice-number guard and navigation.
The UC client retains its existing asynchronous failure behavior.
