# V8.19 Corporate Gift supplier-quote precision

21 October 2026. Release in progress; no production attachment save yet.

## Change

Main and volume-tier unit costs accept step 0.001 with 0.000 placeholders.
Stored values load unchanged, and intentional edits use plain numeric conversion
without rounding. Tooling/sample cost retains its existing cents input.

Existing-quote file additions never invoke automatic or manual AI extraction.
New-quote extraction remains available. When form and tier values are untouched,
an attachment-only transaction updates just the attachment array, preserving all
other fields even when another session changes pricing/notes. Concurrent changes
to attachments reject the save with a reopen message. Actual form edits retain
the existing quote-save behaviour.

Choose supplier file links a PDF/image already uploaded to the selected supplier's
catalogs. It deduplicates by URL, retains original URL/path and supplier file ID,
and performs no Storage upload or AI call. The product/component are not edited.
Numeric input minimum widths and wrapping actions prevent 320px overflow.

## Local verification

Eight isolated actual-form Chrome browser cases PASS:

- Native 1.222 / tier 1.111 validity, placeholders, exact initial fields, four
  viewport widths (320/375/414/1280), no duplicate heading or horizontal overflow.
- Existing-quote PDF upload: zero extraction calls, exactly one attachment-only
  write, reopen retains 1.222 / 1000 / 155, notes, preferred flag and tier 1.111.
- Reused supplier PDF: one linked attachment, duplicate action disabled, no upload
  or extraction, exactly one attachment-only write.
- Concurrent approved price/notes remain intact on attachment save.
- Concurrent attachment change causes a recoverable error and zero writes.
- Intentional main/tier edits save exact 1.223 / 1.112.
- Higher-precision stored 1.22249 / 1.11149 load without rounding.
- New-quote PDF extraction still runs exactly once.

Fixture boundaries replace Firebase/Storage; these cases do not claim live or
emulator rule verification. No rules change is involved. Scripts are committed;
generated screenshots and JSON remain ignored under qa/out/supplier-quote-precision.
