## Maintenance lesson

Keep master-chat state/history and discussDraft in the parent, including the
pending-rule gate and existing redraft/closed-panel completion semantics.
Characterize Enter and button submission, not just markup. For live QA, scope
Send to the input's master-chat container because recipient email actions are
separate controls. Use an unsaved fictional message, then refresh to discard it.
Read textarea live values rather than assuming a value HTML attribute exists.
Do not treat an initial catalogue paint as completed data loading; record the
fully loaded state and inspect product images after refresh.
