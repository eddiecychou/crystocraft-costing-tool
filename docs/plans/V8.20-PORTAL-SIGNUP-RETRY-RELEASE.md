# Portal email registration recovery

The email application now reserves a Firebase user ID and records the submitted details and original invitation in a private Firestore checkpoint before creating the passwordless sign-in. The buyer can submit again in the same browser after a connection loss, page refresh or restart. OC uses the original details for the pending application. Staff approval and the buyer’s password setup still follow the existing workflow.

OC saves the pending profile, invitation and internal alert together and removes the checkpoint in that transaction. A retry after a lost confirmation returns the existing pending result. Delivery continues through the existing alert queue and provider idempotency key.

The browser stores a random retry key under a hash of the normalized email and discards it after confirmation. Firestore stores only the key’s hash. A different browser cannot take over an interrupted request. If the buyer clears browser storage before completion, staff may need to help. Older cached forms can replay their original submission exactly. An older Auth-only account with no checkpoint needs staff review. This release makes no historical account changes and requires no Firebase rules deployment.

## Fictional verification

- All 18 application and alert tests passed. They covered an interruption on either side of Auth creation, simultaneous submissions, a lost response, the original invitation and submitted fields, and one alert. Unrecognized or credentialed sign-ins and changed invitations were protected.
- Chrome used the real portal form and the local Firebase Auth and Firestore emulators. The first submission stopped after Auth creation. A second submission after reload finished the application but lost its response. The third showed the pending confirmation. Readback found one pending profile, one invitation and one captured alert for the buyer.
- The Google application and invitation paths, password setup and approved storefront sign-in also passed in Chrome. All emulator mail was intercepted.
