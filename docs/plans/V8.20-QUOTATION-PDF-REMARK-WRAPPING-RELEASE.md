# Quotation PDF remark wrapping release

Long Chinese descriptions and remarks could cross into the quantity and
price columns. The PDF table now supplies Unicode break opportunities to the
renderer. Slightly tighter row and signature spacing keeps the reported
quotation on one A4 page.
