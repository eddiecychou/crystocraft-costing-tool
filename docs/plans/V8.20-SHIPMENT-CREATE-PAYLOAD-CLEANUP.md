# V8.20 Shipping new-order mapping

orderCreateFields prepares the header used for a new shipment order.
It preserves the source label, uploaded PI reference, header values and
financial conversions. ShipmentForm owns file upload, total calculation,
validation, the create transaction, number allocation, quote linkage
and navigation.
