## Lessons and remaining review

- No horizontal scroll does not prove usable controls: the old flex toolbar had
  a 26px search field while the body overflow check passed. Measure the fields.
- Keep visual size distinct from target size; a smaller mark can remain easy to
  tap without wasting the task text column.
- Use explicit labels and one grid owner. Utility grid-column classes can override
  component-layer rules; avoid conflicting layout definitions on the same node.
- The intended global mobile font floor is less specific than .input. Dashboard
  now uses a scoped override; other forms need a separately scoped audit, recorded
  in TECH-DEBT.md. No global font/padding rollout was applied here.
- Audit within the real OC shell. A fake sidebar omits mobile chrome and bottom
  navigation and gives misleading available-width/height results.
