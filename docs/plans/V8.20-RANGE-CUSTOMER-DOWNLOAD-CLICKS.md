# V8.20 — normal customer Range image downloads

Status: released and verified on 30 October 2026. Normal/native Chrome customer
clicks, saved-file readbacks and all required release gates PASS.

## Report and correction

The existing Range customer gallery rendered an ordinary attachment link without
the HTML download attribute. Automated normal Chrome clicks navigated away from
the product to ERR_BLOCKED_BY_CLIENT, while the same link returned a valid image
and the supported media-download control saved it. Server success alone did not
close the customer's ordinary-click check.

The actual `FigurineDetail` gallery link now cancels attachment-page navigation
and starts the same explicit named native download action as the admin gallery.
It also retains a named download attribute for native link behaviour. The
existing attachment endpoint chooses the final filename, retaining the
previous Unicode-header correction. Gallery layout, source images, customer
visibility, stock/enquiry actions and server security restrictions are unchanged.
No global browser security settings, extensions or Safe Browsing settings were
changed. Chrome's repeated-download prompt was allowed only for the version-specific
production QA address, within the owner's requested multi-image test. Final
verification required actual clicks and complete files with the product page
retained; `downloadMedia` or direct HTTP retrieval did not substitute for clicks.
