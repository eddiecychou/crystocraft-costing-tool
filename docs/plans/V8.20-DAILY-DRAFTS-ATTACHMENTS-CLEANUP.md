## Maintenance lesson

Attachment display depends on parent rules shared across galleries, uploads and
creation payloads. Extract controlled markup without moving those boundaries,
then test the final createDrafts payload as well as local selection behavior.
Keep the existing public/legacy visibility and two-image cap explicit. Cancel
currently retains unsaved link fields, and unlinking a product retains selected
master images; characterization tests preserve those existing behaviors. Live
verification can exercise the controls without AI calls, uploads or persistence.
