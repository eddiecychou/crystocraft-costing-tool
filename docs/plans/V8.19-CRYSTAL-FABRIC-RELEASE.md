# V8.19 Crystal Fabric catalogue merge

19 October 2026. Released; fresh admin and approved-customer checks pass on candidate and production.

## Behaviour and data ownership

Previously the catalogue had no Fabric listing, two extra links to a standalone
Swatch Library, and a physical-sample-only customer flow. Now All Components and
Materials contain one Crystal Fabric range. OC's card opens the original uploader;
the customer card opens /shop/crystal-components/fabric. /shop/swatches redirects
with replacement, so bookmarks land in the same experience.

The card and PDF project existing published crystal_swatches; no new parent/variant
records, duplicated images or speculative inventory SKUs. Read-only live baseline:
156 published photos, 17 colours, styles fabric 108 / legacy rock 48. Legacy rock
keeps the Fine Rock / Rock label, backing codes remain literal. No calibration,
renderer, public WordPress, stock balances or clearance records are changed.

One colour detail form offers project quotation (default) or physical sample.
Project enquiry supports an optional photographed reference, intended application,
notes and the existing private drawing control on Enquiry. It can start before
a swatch or completed drawing is chosen. Project units and null prices stay
explicit; final quotation uses the actual drawing and application. No automatic
area/adhesive/effect estimate. Duplicate project/sample-reference lines are prevented;
distinct references and legacy physical sample carts remain distinct.

New crystal_fabric snapshots preserve source_collection=crystal_swatches, unit=project,
exact optional sample ID/revision, description, protected thumbnail and application.
Sample publication/revision is rechecked before sending. Admin view and enquiry
Excel export preserve these fields. All-unpriced totals remain null / On quotation.
The existing drawing privacy/access rules remain unchanged. No Firebase rules
deployment or production catalogue/data writer is needed.

PDF export re-reads the current published samples and includes one Fabric page
with an actual protected photograph, available reference colours/material labels
and drawing/application quotation text. It does not multiply sample photos into SKUs.
