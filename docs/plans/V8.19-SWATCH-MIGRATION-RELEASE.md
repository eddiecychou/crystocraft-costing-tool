## Using the uploader

1. Open OC → Swatch Library → Upload swatch.
2. Choose the photograph and enter its crystal colour/effect, material and backing
   colour or label. Crop only if useful; the original is kept.
3. Save the draft, open Edit and review the saved photograph/details.
4. Change Visibility to Published when ready for approved customers.
5. Use Archived to withdraw a sample; originals and the existing records remain.

Display order and a short customer-visible description are optional. No stone
pitch, texture measurement, price calculator or renderer setup is required.
