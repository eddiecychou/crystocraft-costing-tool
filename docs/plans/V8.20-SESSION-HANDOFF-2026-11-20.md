## Lessons and skills to carry forward

- For a buyer-facing change, test a second company, a shared browser and a change of account status. Check both the displayed data and the underlying download or export. For historical invoices, pin the issued SI and retain the issued total. [Portal checklist](V8.20-PORTAL-CODE-REVIEW-2026-11-19.md) · [Access rules](../skills/ARCHITECTURE-RULES.md)
- For retries, test a failed write and a successful write whose response is lost. Count the resulting accounts, alerts, orders or invoices. Use a separate request when the operator intends a repeat or reissue. [Sign-up retry evidence](V8.20-PORTAL-SIGNUP-RETRY-RELEASE.md) · [Quote conversion recovery](V8.20-QUOTE-ORDER-CONVERSION-RECOVERY.md)
- Test the artifact the user receives. Open the saved PDF and Excel file, inspect long remarks and totals, and verify an ordinary browser download by its name and bytes. Keep test mail intercepted. [Export and download lessons](V8.20-SESSION-HANDOFF-2026-10-31.md) · [Image-download skill](../skills/oc-image-downloads/SKILL.md)
- Start future maintenance from the feature owner and the current release record. For an authorized release, require both GitHub jobs on the exact application commit. Use fresh admin and approved-buyer sessions on candidate and production, then record the deploy IDs. Documentation-only pushes use `[skip netlify]`.
