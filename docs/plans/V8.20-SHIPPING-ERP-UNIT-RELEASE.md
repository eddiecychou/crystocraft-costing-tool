# Shipping ERP unit adoption release

The ERP comparison feed currently omits units. When adopting an ERP line,
Shipping uses an explicit ERP unit if supplied or the unit on the matching
current draft line. Repeated item codes require an exact one-to-one quantity
and unit price match. A line without a reliable unit uses `pcs` and is listed
for review. The editor and save use the same default.

Fictional tests passed with explicit and missing units, changed quantities
and prices, reordered duplicate codes, and ambiguous lines. The real order
snapshot preparation and reopened editor preserved the adopted quantities and
prices exactly. PI and sales invoice print tables and actual downloaded Excel
files used the saved units. Both new cases failed on the previous form source.
