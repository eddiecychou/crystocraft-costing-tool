# Reference Image Package — v1

What to actually attach to Gemini alongside `../v1-brief.md`, and why. Every
file here was read and visually confirmed (not just copied blind) before
being labeled below.

## Attach these (the actual reference set for v1)

| File | Role | What it shows |
|---|---|---|
| `school-crest.jpg` | **[LOGO REFERENCE — DO NOT MODIFY]** | Clean, high-res version of the official crest: quartered shield (red: star + open book + lamp + 克己復禮; blue: gold zigzag), laurel + holly, "FIDES ET OPERA" banner. This is the definitive logo reference — sharper and cleaner than the building-signage photo. |
| `school-logo.svg` | **[LOGO REFERENCE — DO NOT MODIFY]**, secondary | A separate official wordmark asset (vector) with a small red/purple flame-style mark — not the crest. Included for completeness; the crest is the asset actually used in this concept per `../../03-concept.md`. Flag to Gemini as reference-only if attached, so it doesn't get blended into the crest. |
| `school-building-streetview.jpg` | **[BUILDING REFERENCE]** | The clearest full view of the school's actual curved white facade + signage — the shape Stage 3 wants as the "landmark" silhouette. |
| `school-building-entrance.jpg` | **[BUILDING REFERENCE]**, secondary | Closer entrance-level view with the crest mounted above the sign — useful for how the crest sits on the real building, not for the silhouette itself. |
| `supplier-box-wuhan-front.jpg` | **[STYLE + FORM REFERENCE]** | The clearest single reference for the target illustration style AND the physical box form (rounded MDF corners, kraft-brown edge, raised die-cut plaque, exact composition layout: sky → skyline → foreground). The single most important style reference in this set. |
| `supplier-box-nanjing-3stack.jpg` | **[STYLE REFERENCE]** | Three more examples in one shot (Nanjing, Chongqing, Xiamen) — confirms the style holds across different subjects, useful if Gemini needs more than one example to lock the style in. |
| `supplier-box-spec-sheet.jpg` | **[FORM REFERENCE]** | Exact dimensions (8.7×7.1×4.2cm) and a clean 3/4 view of the box shape/proportions. |

| File | Why excluded |

**Note on `school-students-jumping.jpg`:** these are real, identifiable
children. It should inform the *idea* (small figures, joyful jumping pose)
but must not be used as a literal likeness reference — the brief already
specifies "silhouette figures," which sidesteps this; don't attach this
photo to an actual Gemini call asking it to depict these specific kids.
