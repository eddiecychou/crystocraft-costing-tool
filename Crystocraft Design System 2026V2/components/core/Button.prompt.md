The Crystocraft Button — uppercase, ultra-wide-tracked, zero border-radius. References the geometric wordmark's letter-spacing. Never playful; always precise.

```jsx
<Button variant="primary">Shop Now</Button>
<Button variant="secondary">Request Quote</Button>
<Button variant="ghost">Learn More</Button>
<Button variant="outline">View Collection</Button>
<Button variant="outline-gold">Explore Crystals</Button>
<Button variant="reversed">Light on Dark</Button>
<Button variant="sapphire">Crystals CTA</Button>
<Button variant="burgundy">Bespoke CTA</Button>
<Button size="sm">Small Action</Button>
<Button size="lg">Primary Hero CTA</Button>
<Button disabled>Unavailable</Button>
<Button fullWidth>Full-Width Submit</Button>
<Button href="/collection">Anchor Link</Button>
```

Variants:
- `primary` — ink fill, ivory text; default CTA
- `secondary` — gold fill, ink text; celebratory/gift contexts
- `ghost` — transparent, ink text; tertiary actions
- `outline` — ink border, fills on hover; secondary actions
- `outline-gold` — gold border, for use on dark backgrounds
- `reversed` — ivory fill, ink text; dark-background hero sections
- `sapphire` — for Crystocraft Crystals division CTAs
- `burgundy` — for Crystocraft Bespoke Gifting CTAs
